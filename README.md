# Session Controller

Приложение для Windows, которое помогает не оставлять свои аккаунты на общих
компьютерах (например, в учебной аудитории).

Нажал **«Начать сессию»** → вошёл куда нужно → нажал **«Завершить сессию»**
(или просто выключил компьютер) → на компьютере не осталось ни одного входа,
сделанного за сессию.

> Статус: ранняя разработка (Этап 0). Кнопки пока только меняют статус,
> реальная очистка появится на Этапе 1.
> Подробный план — в [docs/PLAN.md](docs/PLAN.md).

## Запуск из исходников (Windows)

Нужен Python 3.12 или новее: <https://www.python.org/downloads/>
(при установке отметь «Add python.exe to PATH»).

В папке проекта (PowerShell или cmd):

```bat
py -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python -m session_controller
```

Первые две команды нужны один раз, дальше достаточно последней.
