# Session Controller

Программа для Windows, которая помогает не оставлять свои аккаунты на общих
компьютерах — например, в учебной аудитории.

1. Нажал **«Начать сессию»**.
2. Работаешь как обычно: браузер, Telegram, Discord, Steam, VS Code — открываешь,
   закрываешь, входишь в аккаунты, всё сохраняется.
3. Нажал **«Завершить сессию»** или просто выключил компьютер — и твоих входов
   на компьютере больше нет.

**Как это работает.** В начале сессии программа запоминает, как выглядели
программы до тебя, а в конце возвращает всё как было. Поэтому неважно, на каком
сайте или в каком приложении ты входил: всё, что появилось за сессию, исчезает.

## Скачать

Скачай **`SessionController-Setup-<версия>.exe`** на странице
[Releases](https://github.com/maybenextimeee/session_controller/releases) и запусти.

- Нужна **64-битная Windows 10 или 11** — на 32-битной программа не работает.
- Права администратора не нужны: программа ставится только для тебя
  (для текущего пользователя Windows).
- Галочка **«Запускать вместе с Windows»** в установщике: программа сама будет
  появляться в трее при входе в Windows. Так она не пропустит выключение
  компьютера. Её можно включить и потом, в настройках.
- Если Windows покажет синее окно «Система Windows защитила ваш компьютер»,
  нажми **«Подробнее» → «Выполнить в любом случае»**. Так бывает с новыми
  программами без цифровой подписи.

**Обновление:** просто установи новую версию поверх старой.
**Удаление:** «Параметры → Приложения → Session Controller». Если идёт сессия,
сначала заверши её.

## Что очищается

| Программа | Что удаляется |
|---|---|
| Браузеры: Chrome, Edge, Яндекс, Opera, Opera GX, Brave, Vivaldi, Firefox | Входы на сайты, сохранённые пароли, история, закладки, расширения |
| Telegram Desktop | Вход и кэш переписки |
| Discord | Вход |
| Steam | Вход, запомненные аккаунты, вход в магазин внутри Steam |
| VS Code | Вход в GitHub / Microsoft, настройки, история |
| Git и GitHub | Настройки Git (имя, почта), SSH-ключи, вход в GitHub CLI и GitHub Desktop |
| VPN: Happ, v2RayTun, Hiddify, Clash Verge | Подписки, ключи, серверы. Настройки прокси Windows возвращаются как были |
| ИИ: Claude for Desktop, Claude Code, ChatGPT, Codex, Cursor | Вход, чаты, настройки |
| Диспетчер учётных данных Windows | Пароли и токены, которые программы сохранили за сессию |

В окне показаны программы, найденные на компьютере, — любую можно выключить
переключателем. Полный список открывает кнопка **«Все поддерживаемые программы»**.

Программы, которых на компьютере нет, тоже под защитой: если их установят и
запустят во время сессии, при завершении их данные удалятся. Новая программа
появится в списке после перезапуска Session Controller.

## Настройки

Кнопка с шестерёнкой справа вверху (выйти — кнопкой «назад» или Esc):

- **Тема** — светлая, тёмная или как в Windows (так при первом запуске).
- **Выходить из аккаунтов при выключении компьютера** — включено по умолчанию.
  Если выключить, сессия переживёт выключение и продолжится после включения.
- **Запускать вместе с Windows** — программа сама появится в трее при входе.

Крестик в углу окна не закрывает программу, а прячет её в трей (значок возле
часов): так она не пропустит выключение компьютера. Совсем выйти — через меню
этого значка.

## ⚠️ Важно знать

- Возвращается **всё**, что сделано в этих программах за сессию, а не только
  входы: например, история и закладки браузера, настройки VS Code. Файлы в
  «Загрузках» и твои документы и проекты на диске не трогаются.
- В начале и в конце сессии выбранные программы закрываются — **несохранённое в
  них пропадёт**. VPN при этом отключается: просто подключись заново.
- Чтобы выход сработал при выключении компьютера, Session Controller должен быть
  запущен (значок в трее). Проще всего — включить «Запускать вместе с Windows».
- Если компьютер выключился аварийно (выдернули питание, всё зависло), сессия
  дочистится при следующем запуске Session Controller — если включён выход при
  выключении компьютера.
- «Claude Code» возвращает к состоянию до сессии свою папку `.claude` (историю,
  настройки, память). На своём компьютере, где ты работаешь с Claude Code, его
  лучше выключить в списке.

## Если что-то пошло не так

- **«Не удалось очистить: …»** — скорее всего, программа не дала себя закрыть.
  Закрой её вручную и нажми «Завершить сессию» ещё раз: сессия не теряется,
  пока не будет полностью завершена.
- **«Не получится начать сессию: Session Controller запущен изнутри …»** —
  программу открыли, например, из терминала другой программы из списка.
  Запусти Session Controller из меню «Пуск» или выключи эту программу в списке.
- **Нашёл ошибку или хочешь новую программу в списке** — напиши в
  [Issues](https://github.com/maybenextimeee/session_controller/issues) и приложи
  лог: `%LOCALAPPDATA%\SessionController\log.txt` (вставь этот путь в адресную
  строку Проводника). Ссылка «Папка с логом» есть и в настройках.

Программа в ранней версии — спасибо, что пробуешь её.
