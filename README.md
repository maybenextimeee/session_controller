# Session Controller

Приложение для Windows, которое помогает не оставлять свои аккаунты на общих
компьютерах (например, в учебной аудитории).

1. Нажал **«Начать сессию»**.
2. Работаешь в своём обычном браузере: открываешь, закрываешь, входишь в аккаунты —
   всё сохраняется.
3. Нажал **«Завершить сессию»** или выключил компьютер (если стоит галочка
   «Выходить из аккаунтов при выключении компьютера») — браузеры вернулись
   к состоянию до начала сессии, твоих входов на компьютере больше нет.

Поддерживаются Chrome, Edge, Яндекс Браузер, Opera, Opera GX, Brave, Vivaldi, Firefox.

> Статус: ранняя разработка. Подробный план — в [docs/PLAN.md](docs/PLAN.md).

## ⚠️ Перед первым запуском

- При завершении сессии откатывается **всё**, что сделано в браузерах за сессию:
  входы, пароли, история, закладки, настройки, расширения. Файлы в «Загрузках»
  не трогаются.
- Программа пока не проверена на реальной Windows. Первые тесты лучше делать,
  понимая, что снимок браузеров до начала сессии лежит в
  `%LOCALAPPDATA%\SessionController\backup` (он удаляется после завершения сессии).
- Если что-то пошло не так, пригодится лог: `%LOCALAPPDATA%\SessionController\log.txt`.

## Запуск из исходников (Windows)

Нужен Python 3.12 или новее: <https://www.python.org/downloads/>
(при установке отметь «Add python.exe to PATH»).

В папке проекта (PowerShell или cmd):

```bat
py -m venv .venv
.venv\Scripts\python -m pip install -r requirements-dev.txt
.venv\Scripts\python -m session_controller
```

Первые две команды нужны один раз (и после изменения `requirements*.txt`),
дальше достаточно последней.

Тесты движка:

```bat
.venv\Scripts\python -m pytest
```

## Структура

```
session_controller/
├── __main__.py   ← точка входа (python -m session_controller)
├── app.py        ← окно, кнопки, галочка, трей, реакция на выключение Windows
├── session.py    ← движок: начать / завершить сессию, журнал, восстановление
├── browsers.py   ← какие браузеры бывают, где их данные, как их закрыть
├── snapshot.py   ← снимок папки и откат к нему
├── settings.py   ← настройки
├── paths.py      ← где лежат файлы программы
└── winapi.py     ← функции Windows, которых нет в Qt
tests/            ← тесты (pytest)
docs/PLAN.md      ← план проекта, этапы, архитектура
```
