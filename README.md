## Как это работает

1. Выберите в каталоге установленные программы, которые хотите включить в сессию.
2. Нажмите **«Начать сессию»**. Приложение сохранит состояние их локальных профилей.
3. Нажмите **«Завершить сессию»**. Session Controller восстановит профили, включая прежние настройки и данные. Входы и другие изменения, сделанные в этих профилях за сессию, будут удалены.

Часто используемые программы можно закрепить на главном экране и менять их порядок перетаскиванием.

## Что восстанавливается после сессии

Session Controller возвращает данные выбранных программ к состоянию на момент начала сессии. Например, вход в браузере, который уже был сохранён до начала работы, останется, а вход, выполненный во время сессии, исчезнет из локального профиля.

| Программа | Какие данные затрагивает восстановление |
| --- | --- |
| **Браузеры** — Chrome, Edge, Яндекс Браузер, Opera, Opera GX, Brave, Vivaldi, Firefox | Входы на сайты, сохранённые пароли, история, закладки и расширения |
| **Telegram Desktop и Discord** | Локальные данные входа и кэш |
| **Steam** | Вход в клиент, запомненные аккаунты и вход во встроенный магазин |
| **VS Code** | Локальные данные входа, в том числе в GitHub и Microsoft, настройки и история |
| **Git и GitHub** | Локальные настройки Git, SSH-ключи, вход в GitHub CLI и GitHub Desktop |
| **VPN** — Happ, v2RayTun, Hiddify, Clash Verge, AmneziaVPN | Подписки, ключи и данные серверов в профилях клиентов. Настройки прокси Windows возвращаются к состоянию до сессии |
| **ИИ-приложения** — Claude for Desktop, Claude Code, ChatGPT и Codex, Cursor, Google Antigravity и Antigravity IDE | Входы, локальная история и настройки в поддерживаемых папках. Данные в папке `Claude-Data`, включая файлы Cowork, остаются на месте |
| **Диспетчер учётных данных Windows** | Записи, сохранённые приложениями в системном хранилище, в том числе пароли и токены |

## Что важно знать

- **Сохраните работу перед началом и завершением сессии.** Session Controller закрывает выбранные программы на обоих этапах. При завершении VPN-клиенты закрываются последними.
- **В сессию входят программы, выбранные при её начале.** После установки новой программы перезапустите Session Controller, чтобы она стала доступна в каталоге.
- **При выключении Windows Session Controller должен работать.** Для автоматического завершения сессии включите соответствующую настройку и оставьте приложение в трее. При желании включите запуск вместе с Windows.
- **Очистка «Загрузок» включается отдельно.** По умолчанию она выключена. Если включить её до начала сессии, при завершении будут безвозвратно удалены файлы и папки, появившиеся в «Загрузках» за это время.
- **Можно завершить сессию и сохранить текущее состояние программ.** Нажмите правой кнопкой мыши на «Завершить сессию» и выберите **«Завершить без выхода из аккаунтов»**.

## Установка

На странице релиза скачайте файл `SessionController-Setup-*.exe` из раздела **Assets** и запустите его. Права администратора для установки не требуются.

## Обратная связь

Если вы нашли ошибку или хотите предложить программу для каталога, создайте обращение в [GitHub Issues](https://github.com/maybenextimeee/session_controller/issues). При сообщении об ошибке укажите версию Session Controller и опишите, как её повторить. Журнал можно найти через **«Папка с логом»** в настройках. Перед публикацией проверьте, что в нём нет личных данных.
