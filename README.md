# Session Controller

Session Controller помогает работать на общем компьютере. Начни сессию перед работой, а в конце нажми «Завершить сессию». Выбранные программы вернутся к состоянию до её начала.

## Скачать

Скачай **SessionController-Setup-0.8.0.exe** со страницы релиза и запусти. Программа поддерживает 64-битные Windows 10 и 11. Права администратора для установки не нужны. [Релизы на GitHub](https://github.com/maybenextimeee/session_controller/releases)

Чтобы обновиться, запусти установщик новой версии. Для удаления открой «Параметры» → «Приложения» → Session Controller.

## Сессии

1. В «Каталоге программ» выбери, какие программы нужно очищать. Булавка добавляет программу на главный экран. Чтобы изменить порядок закреплённых, потяни карточку вверх или вниз.
2. Нажми **«Начать сессию»** и работай как обычно.
3. Нажми **«Завершить сессию»**, когда закончишь. В настройках можно включить автоматическое завершение при выключении Windows.

Поддерживаются популярные браузеры, Telegram, Discord, Steam, VS Code, Git, VPN, ИИ-клиенты и Диспетчер учётных данных Windows. Точный список есть в каталоге программы.

В начале и в конце сессии выбранные программы закрываются. Сохрани свою работу заранее. Изменения в их профилях откатываются целиком, включая историю, настройки и закладки. Очистка скачанных файлов включается отдельно.

## Аккаунт и записи

Нажми на аватарку рядом с настройками, чтобы зарегистрироваться или войти. На вкладке **«Пароли»** можно создавать записи с собственными полями. Правый клик открывает команды редактирования и удаления.

Записи доступны на других компьютерах после входа в тот же аккаунт. Для этого нужны интернет и доступность сервиса аккаунтов. Содержимое записей хранится на сервере в открытом виде. Для важных паролей используй отдельное защищённое хранилище.

Чтобы завершение сессии также удаляло сохранённый вход в Session Controller на этом компьютере, включи соответствующий пункт в каталоге перед началом сессии.
