# Источники значков

- Chrome, Яндекс Браузер, Brave, Vivaldi, Opera, Opera GX, Firefox, Telegram Desktop, Discord, Steam, v2RayTun, AmneziaVPN и Cursor — значки с сайтов соответствующих продуктов.
- Edge, VS Code, Happ и Google Antigravity — значки из оригинальных Windows-приложений.
- Git, Hiddify и Clash Verge — значок с [сайта Git](https://git-scm.com/about/logo) и значки из репозиториев [Hiddify](https://github.com/hiddify/hiddify-app) и [Clash Verge Rev](https://github.com/clash-verge-rev/clash-verge-rev).
- Claude и Claude Code — значки из приложения [Claude](https://claude.ai/images/claude_app_icon.png) и [документации Claude Code](https://code.claude.com/docs/en/overview).
- Для карточки ChatGPT и Codex используется [значок ChatGPT от OpenAI](https://cdn.oaistatic.com/assets/favicon-o20kmmos.svg).
- Диспетчер учётных данных и «Загрузки» — символы из [Microsoft Fluent UI System Icons](https://github.com/microsoft/fluentui-system-icons).

Значки обозначают приложения в списке. Товарные знаки принадлежат их правообладателям.
