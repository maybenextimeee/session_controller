## ⬇️ Как установить

1. Скачай **`SessionController-Setup-….exe`** ниже, в разделе **Assets**.
2. Запусти его. Права администратора не нужны — программа ставится для текущего пользователя Windows.
3. Если Windows покажет окно «Система Windows защитила ваш компьютер», нажми **«Подробнее» → «Выполнить в любом случае»**. Так бывает с новыми программами без цифровой подписи.

**Обновление:** просто установи новую версию поверх старой.
**Удаление:** «Параметры → Приложения → Session Controller». Если идёт сессия, сначала заверши её.

## Что умеет

Нажал **«Начать сессию»** → вошёл куда нужно → нажал **«Завершить сессию»** или выключил компьютер — и твоих входов на компьютере не осталось.

Очищается: браузеры (Chrome, Edge, Яндекс, Opera, Brave, Vivaldi, Firefox), Telegram, Discord, Steam, VS Code, Git и GitHub, Диспетчер учётных данных Windows.
