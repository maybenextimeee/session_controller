## ⬇️ Как установить

1. Скачай **`SessionController-Setup-….exe`** ниже, в разделе **Assets**.
2. Запусти его. Права администратора не нужны — программа ставится для текущего пользователя Windows.
3. Если Windows покажет окно «Система Windows защитила ваш компьютер», нажми **«Подробнее» → «Выполнить в любом случае»**. Так бывает с новыми программами без цифровой подписи.

**Обновление:** просто установи новую версию поверх старой.
**Удаление:** «Параметры → Приложения → Session Controller». Если идёт сессия, сначала заверши её.

## Что нового в 0.5.0

- **Новый дизайн:** светлая и тёмная тема (по умолчанию как в Windows), значки программ, одна кнопка сессии внизу — на ней видно, сколько идёт сессия.
- **VPN-клиенты:** Happ, v2RayTun, Hiddify, Clash Verge. Вместе с ними возвращаются настройки прокси Windows — интернет после сессии не пропадёт.
- **ИИ-клиенты:** Claude for Desktop, Claude Code, ChatGPT, Codex, Cursor.
- **«Все поддерживаемые программы»:** полный список одной кнопкой. Программы, которых ещё нет на компьютере (в том числе Steam), тоже под защитой: установят их во время сессии — данные удалятся при завершении.
- **VS Code 1.118 и новее:** вход в GitHub теперь действительно удаляется.
- Свои окна-вопросы вместо стандартных окон Windows, выход из настроек по Esc.

## Что умеет

Нажал **«Начать сессию»** → вошёл куда нужно → нажал **«Завершить сессию»** или выключил компьютер — и твоих входов на компьютере не осталось.

Очищается: браузеры (Chrome, Edge, Яндекс, Opera, Brave, Vivaldi, Firefox), Telegram, Discord, Steam, VS Code, Git и GitHub, VPN-клиенты (Happ, v2RayTun, Hiddify, Clash Verge), ИИ-клиенты (Claude for Desktop, Claude Code, ChatGPT, Codex, Cursor), Диспетчер учётных данных Windows.

⚠️ «Claude Code» возвращает папку `~\.claude` к состоянию до сессии. На своём компьютере, где ты работаешь с Claude Code, его лучше выключить в списке.
