# История изменений

## 0.8.1

- В форме регистрации появилось подтверждение пароля. Обновлены карточка профиля и расположение кнопок входа и выхода.
- Записи на вкладке «Пароли» пронумерованы. Их можно переставлять перетаскиванием, порядок сохраняется в аккаунте.
- Можно создать до 50 записей на аккаунт и указать до пяти полей в записи.
- При завершении сессии очищаются выбранные при старте программы. VPN-клиенты закрываются последними.
- В меню правой кнопки на «Завершить сессию» появился пункт «Завершить без выхода из аккаунтов». Он сохраняет текущее состояние программ.
- Ускорены копирование и восстановление профилей. Улучшено закрытие ChatGPT и Codex, когда их фоновые процессы удерживают файлы.
- На главной странице прокручивается только список закреплённых приложений. Заголовок, каталог и кнопка сессии остаются на месте.
- При запуске с включённой проверкой обновлений приложение сверяется с релизом GitHub Latest.

## 0.8.0

- Аккаунт Session Controller с аватаркой, редактированием профиля и сохранённым входом.
- Записи для сервисов с настраиваемыми полями. Доступны с разных компьютеров после входа в аккаунт.
- Выход из аккаунта при завершении сессии, если включён соответствующий пункт в каталоге.
- Плавная перестановка закреплённых программ перетаскиванием. Прокрутка каталога стала медленнее и плавнее.

## 0.7.0

- Кнопка сессии равномерно меняет цвет за 120 мс. Во время сессии она совпадает с фоном окна и выделена белой обводкой.
- Карточки закреплённых программ раскрываются и сворачиваются вместе с отступами. В кнопке каталога остались название и число программ.
- Фиксированный размер окна, цветные значки приложений и кнопки-булавки. Настройки открываются со сдвигом.
- Убраны счётчик закреплений, пояснения в настройках и пульсация активной сессии. Под кнопкой завершения отображается время начала.
- Завершение фоновых операций сессии обрабатывается в потоке интерфейса после остановки рабочего потока.

- Исправлен запуск Windows-сборки на компьютерах, где другие программы добавили свою версию ICU в PATH.
- Новый монохромный интерфейс и геометрический логотип с откликом на нажатие.
- Главная показывает закреплённые программы. Булавка в каталоге добавляет карточку, повторное нажатие убирает её. Выбор программ для очистки сохраняется отдельно.
- В настройках можно переключаться между русским и английским.

- Исправлено обнаружение Git для Windows, Happ и Claude Desktop. Для определения установки теперь учитываются исполняемые файлы и регистрация пакетов MSIX.
- ChatGPT и Codex в одной карточке с общим переключателем. Если раньше хотя бы одна из этих карточек была выключена, общий переключатель тоже выключен.
- Для общей карточки используется значок ChatGPT от OpenAI.
- У Happ учитывается папка данных в `%LOCALAPPDATA%\Happ`. Папка Claude Desktop `Claude-Data` учитывается при обнаружении и сохраняется при завершении сессии.
- Обновлены значки всех карточек. Они входят в сборку и отображаются даже у программ, которых ещё нет на компьютере. Значок из документации Anthropic заменил временный значок терминала у Claude Code.
- Добавлена карточка **Google Antigravity**. Она отвечает за приложение Antigravity и Antigravity IDE, возвращая их профили и локальные данные агента к состоянию до сессии.

## 0.6.0

- **Окно больше не подвисает** при начале и завершении сессии: снимок и очистка идут в фоне, а на кнопке виден прогресс — «Сохраняю · Google Chrome · 2 из 7».

## 0.5.0

- **Новый дизайн:** светлая и тёмная тема (по умолчанию как в Windows), значки программ, одна кнопка сессии внизу — на ней видно, сколько идёт сессия.
- **VPN-клиенты:** Happ, v2RayTun, Hiddify, Clash Verge. Вместе с ними возвращаются настройки прокси Windows — интернет после сессии не пропадёт.
- **ИИ-клиенты:** Claude for Desktop, Claude Code, ChatGPT, Codex, Cursor.
- **«Все поддерживаемые программы»:** полный список одной кнопкой. Программы, которых ещё нет на компьютере (в том числе Steam), тоже под защитой: установят их во время сессии — данные удалятся при завершении.
- **VS Code 1.118 и новее:** вход в GitHub теперь действительно удаляется.
- Свои окна-вопросы вместо стандартных окон Windows, выход из настроек по Esc.
